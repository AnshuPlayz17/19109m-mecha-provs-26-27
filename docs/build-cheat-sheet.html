02Size limits

  • Folded, nothing sticks up past the base stage: 17.75" tall, 0.25" under 18".
  • Nothing pokes out of the 18" cube at the start: toggle arm, balancers, claw funnels, tank fittings, wires.
  • All the way up, nothing reaches 50". The claw tops out at 47.75", so nothing on it can stick up more than ~2.25" (check with the arm flip up).
  • Check the start size with a real 18" box before every event.

03Drivetrain

wheel motor C-channel
  • Track width 12" (24 holes), wheel center to wheel center. Narrower tips with the cascade up.
  • Gap between the inner rails about 10": the cascade (about 9.5") fits with ~0.25" each side.
  • Middle wheel shifted back, under the cascade's weight. Leave a gap so it doesn't rub the back wheel.
  • Stagger the left and right motors along the length so they don't hit in the middle.
  • No slop: every axle in bearings on both rails, shaft collars tight, no wobble when you shake a wheel.
  • Spin each side by hand: it rolls freely and feels the same as the other side.
  • Battery and drive motors as low as they go.

05Tracking wheels

  • The wheel stays on the floor when the robot rocks or a drive wheel lifts.
  • Sensor right on the wheel's axle: no gears, no slop.
  • The pivot doesn't wobble side to side.
  • Push the robot one tile (23.8") by hand: the check screen should read close to 23.8.

06Cascade + balancers

  • 3 stages of 35 holes, 5-hole overlap: 30" of travel, claw tops out at 47.75".
  • Brace every stage. 2.5" is the least overlap that works, so no wobble allowed.
  • Hardstops at the bottom and top. It starts every match all the way down (the code zeroes there).
  • Rotation sensor on the spool axle, so it counts exactly what the spool does.
  • Balancers: a piston pushes them out by itself near the top, and they come back in as it drops. They fold inside the 18" cube.
  • Bands or springs keep the balancers fully in when there's no air.

07Cascade + intake motors

  • All 3 cascade motors on the same shaft (or geared together) so they can't fight each other.
  • The toggle arm runs off the spool: it swings out as the cascade rises. Make sure it never sticks out past 18" at the start or hits a goal while scoring.
  • Lift the heaviest real load (claw + a full stack) all the way up before building the rest.
  • The cascade holds its height on its own when the motors brake. If it slides down, add rubber bands to help it.
  • The intake runs any time, even while the cascade moves.

08Air

  • Fill valve → Tank A → Tank B → gauge → the 3 solenoids.
  • Pump to the game manual's limit before every match.
  • Each solenoid right next to its piston, so that tube is only a few inches.
  • Single-acting pistons (claw, balancers): plug the solenoid's second port. Bands return them.
  • Gauge where you can read it from outside the robot.
  • Soapy water on every fitting while it's full: bubbles mean a leak.
  • Bench test: a full skills run of piston moves. Write down the pressure at the end.
Decide: clawThe code has air closes the claw, bands open it. The old air diagram had it the other way. Pick one and tell Claude.

09Wiring + consistency

Wiring

  • Label both ends of every cable with what it is (ports come later).
  • Strain relief near every plug: zip-tie it so a tug never pulls the plug.
  • No cable near a gear, wheel or sharp edge, and none crosses the cascade's path.
  • Slack on cables that ride up the cascade, routed so they can't snag.
  • Battery swaps in under 10 s without touching other cables.
  • Brain screen and controller port easy to reach.

Same every match

  • Starting jig: puts the robot in the same spot every time.
  • Funnels on the claw: it grabs a pin even an inch off.
  • Hardstops on everything that moves: toggle arm, arm flip, claw, cascade.
  • Toggle arm folded at the start, with the cascade all the way down.
  • No slop in the drive or the tracking wheels.
  • Pre-auto check screen all green before every match.

Match loading

  • Main way: back of the robot. The load drops into the open claw; the claw sensor sees it, the claw closes and lifts. About 0.5 s.
  • Poly funnel at the back so a load an inch off still drops in straight.
  • A guide so the robot backs up to the loader in the same spot every time.
  • Other way: intake. Same poly piece; use it only when the route faces that way.
